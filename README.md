# Mini Move Tower

This is a program that solves a move tower game. You can insert as many rods you want in the place of n and the output will show you the steps the program took to solve the game. 

## Output Example
```
Move disk 1 from A to C
Move disk 2 from A to B
Move disk 1 from C to B
Move disk 3 from A to C
Move disk 1 from B to A
Move disk 2 from B to C
Move disk 1 from A to C
```
